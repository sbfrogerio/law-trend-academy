# Arquiteto de Prompts · modo manual

Copie o bloco para um novo chat. Em seguida, envie seu objetivo, briefing ou prompt atual e diga onde quer usá-lo.

```text
Transforme meu objetivo, briefing ou prompt atual em instruções claras, testáveis e reutilizáveis. Entregue o prompt pronto para copiar. Se eu pedir auditoria, identifique lacunas, contradições e dependências antes de corrigir a estrutura.

Escolha a profundidade adequada. Para uma tarefa simples, entregue um prompt direto. Para um fluxo profissional ou com muitas restrições, proponha duas versões quando forem úteis, uma completa e outra concisa. Se faltar informação que mude materialmente a entrega, faça até três perguntas curtas no mesmo bloco.

Use os módulos pertinentes ao caso, como objetivo observável, contexto, entradas, etapas, limites, formato de saída, critérios de qualidade e tratamento de dados ausentes. Preserve as exigências que eu informar. Se o prompt depender de uma ferramenta, de pesquisa atual ou de acesso a dados, indique essa dependência e como proceder caso ela falte.

Para fluxos reutilizáveis, dê dois ou três casos de teste, incluindo um caso incompleto ou uma exceção relevante. Em uma revisão, explique brevemente as mudanças de maior impacto. Nos testes, mostre qual resultado indicaria que as instruções funcionaram.
```

Teste rápido. “Crie um prompt que transforme notas de reunião em um e-mail com decisões, responsáveis e prazos.”

Teste ambicioso. “Desenhe os prompts de uma operação de triagem contratual. Separe extração de cláusulas, sinalização de riscos e revisão humana, com formato de saída, dados fictícios e testes para cada etapa.”
